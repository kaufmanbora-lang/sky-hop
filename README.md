# Sky Hop

Браузерная игра для Meta Ray-Ban Display, адаптированная под экран 600×600 и Meta Neural Band.

## Управление

- Meta Neural Band: большой + указательный палец — взмах вверх / подтверждение в меню.
- Meta Neural Band: большой + средний палец — рывок вниз / назад.
- Сенсор очков: касание одним пальцем — взмах вверх.
- Сенсор очков: касание двумя пальцами — рывок вниз.
- Сенсор очков: двойное касание двумя пальцами — выход из раунда в меню.
- Компьютер: `Пробел` — вверх, `Ctrl` — вниз.
- Свайпы D-pad (`Arrow`-клавиши) — перемещение фокуса и прокрутка списков.
- Во время эффекта «Реверс» команды вверх и вниз временно меняются местами.

## Что реализовано

- Победный маршрут из 1000 труб и одно очко/одна монета за каждую трубу.
- Новый сектор каждые 100 труб: трубы меняют оттенок и темнеют, скорость растёт, проход сужается до безопасного предела; в каждом новом секторе появляется сердце.
- После 1000-й трубы проигрывается квадратный финальный ролик 600×600 без обрезания, а профиль навсегда получает звание «Победитель».
- Избегаемые модификаторы между трубами: реверс и ускорение.
- Анимация столкновения, падение птицы, шлейф, синтезированные эффекты и спокойная оригинальная музыка.
- Таблица лучших раундов с датами.
- Магазин шлейфов: золотой — 100, сверхгалактический — 200, карточный — 300.
- Семь рангов по общему количеству труб; «Небесный титан» открывается на 100 000.
- Автоматический профиль устройства без регистрации, почты и пароля. При повторном запуске игра сразу открывает тот же профиль и сохраняет весь прогресс этих очков.
- Неблокирующий запуск: игра стартует независимо от загрузки музыки, а при сбое изображения использует встроенную резервную графику вместо бесконечного экрана загрузки.
- Усиленный взмах вверх: одиночное нажатие поднимает выше, а быстрая серия нажатий добавляет ограниченное ускорение подъёма.

## Локальный запуск

Откройте папку через любой статический HTTP-сервер. Например:

```powershell
python -m http.server 4173 --bind 127.0.0.1
```

Затем откройте `http://localhost:4173/?desktop=1`.

Управление компьютерного теста:

- `Пробел` — взмах вверх.
- `Ctrl` — рывок вниз.
- Стрелки — навигация по меню.
- `Enter` — выбрать пункт.
- `Escape` — вернуться назад.
- Все кнопки также работают мышью.

Файл `start-local-test.cmd` запускает локальный сервер и открывает компьютерный режим автоматически.

## Запуск на Meta Ray-Ban Display

1. Разместите содержимое этой папки на публичном HTTPS-хостинге. Для Render уже добавлен готовый файл `render.yaml`; подробная пошаговая инструкция находится в `RENDER-INSTALL.md`.
2. Откройте Meta AI на телефоне.
3. Перейдите: Devices → Display Glasses settings → App connections → Web apps.
4. Нажмите Add a web app и вставьте HTTPS-адрес с параметром актуальной сборки: `?release=modifier5`.

## Профиль устройства

При первом запуске игра автоматически создаёт уникальный локальный профиль для текущих очков/браузера. Вводить почту и пароль не нужно; при следующих запусках сразу открывается главное меню. Очки, покупки, результаты и ранги хранятся в браузерном хранилище этого устройства. Очистка данных Web App удалит локальный профиль и прогресс. Для облачного переноса на другие очки понадобится отдельная база данных.

## Состав

- `index.html` — интерфейс всех экранов.
- `styles.css` — визуальная система и фокус-состояния Neural Band/D-pad.
- `app.js` — игровой цикл, физика, звук, профиль, магазин, ранги и результаты.
- `assets/` — оптимизированные игровые изображения, музыка, звуки и финальный ролик.
- `design/` — утверждённый визуальный концепт и концепт экранов.
- `render.yaml` — готовый Blueprint для бесплатного статического сайта Render.
- `RENDER-INSTALL.md` — подробная инструкция публикации и подключения к очкам.
