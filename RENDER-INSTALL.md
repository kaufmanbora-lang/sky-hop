# Публикация Sky Hop на Render

После публикации игра будет работать по публичному HTTPS-адресу из любой точки мира, даже когда ваш компьютер выключен. Render будет хранить и раздавать файлы игры через собственный глобальный CDN.

## Что подготовлено

- `render.yaml` — готовая конфигурация Render Blueprint.
- Тип сервиса — бесплатный статический сайт.
- Папка публикации — корень проекта.
- Автоматический HTTPS и публичный адрес `*.onrender.com`.
- Автоматическое обновление после каждого нового коммита в подключённый репозиторий.
- Все игровые изображения, музыка, звуки и финальный ролик находятся внутри проекта.

## Шаг 1. Загрузите проект на GitHub

Render берёт файлы из GitHub, GitLab или Bitbucket. ZIP-файл непосредственно в Render не загружается.

1. Распакуйте `sky-hop-webapp.zip`.
2. Создайте новый пустой репозиторий на GitHub, например `sky-hop-meta-rayban`.
3. Нажмите `Add file` → `Upload files`.
4. Перетащите **всё содержимое** распакованной папки, включая:
   - `render.yaml`;
   - `index.html`;
   - `app.js`;
   - `styles.css`;
   - папку `assets`.
5. Нажмите `Commit changes`.

Важно: файл `render.yaml` должен находиться в корне репозитория рядом с `index.html`, а не внутри дополнительной вложенной папки.

## Шаг 2. Создайте Blueprint на Render

1. Откройте `https://dashboard.render.com/` и войдите в аккаунт.
2. Нажмите `New` → `Blueprint`.
3. Подключите GitHub, если он ещё не подключён.
4. Выберите репозиторий `sky-hop-meta-rayban`.
5. В поле Blueprint Path оставьте `render.yaml`.
6. Нажмите `Apply` или `Deploy Blueprint`.
7. Дождитесь статуса `Live`.

Важно: в `render.yaml` для статического сайта намеренно нет строки `plan: free`. Render определяет бесплатный статический режим по `runtime: static`; поле `plan` для этого типа вызывает ошибку `no such plan free for service type web`.

Render выдаст постоянный адрес примерно такого вида:

```text
https://sky-hop-meta-rayban.onrender.com
```

Название может немного отличаться, если такой адрес уже занят.

## Шаг 3. Проверьте публикацию

1. Откройте адрес Render в режиме инкогнито на телефоне или компьютере.
2. Убедитесь, что появляется экран входа Sky Hop.
3. Проверьте запуск игры, музыку и финальный ролик.

Для компьютерного теста можно добавить `?desktop=1`:

```text
https://sky-hop-meta-rayban.onrender.com/?desktop=1
```

Для очков используйте чистый адрес **без** `?desktop=1`.

## Шаг 4. Добавьте игру на Meta Ray-Ban Display

1. Откройте приложение Meta AI на телефоне.
2. Перейдите `Devices` → `Display Glasses settings`.
3. Откройте `App connections` → `Web apps`.
4. Нажмите `Add a web app`.
5. Укажите название `Sky Hop`.
6. Вставьте чистый HTTPS-адрес Render.
7. Подтвердите добавление.

## Как выпускать обновления

После изменений загрузите обновлённые файлы в тот же GitHub-репозиторий. Render автоматически опубликует новую версию по прежнему адресу. Повторно добавлять приложение на очки не нужно.

## Важное ограничение текущей версии

Профиль, пароль, результаты, ранги и покупки хранятся локально в браузерном хранилище конкретных очков. Render обеспечивает постоянную доступность игры, но не переносит прогресс между разными очками. Для общего облачного аккаунта потребуется отдельная база данных и сервер авторизации.
